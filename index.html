🤝 Real-time Sync (Firebase)

🔥 Setup Firebase for Real-time Sync:

  1. Go to firebase.google.com
  2. Click "Get Started" → "Create a project" (name: "singapore-checklist")
  3. Create a Realtime Database (not Firestore)
  4. Go to Project Settings (gear icon) → "Your apps" → Add Web App
  5. Copy the config object (it looks like below)
  6. Paste it in the JavaScript code where it says "YOUR_CONFIG_HERE"

Your config will look like this:

const firebaseConfig = {
apiKey: "AIzaSy...",
authDomain: "your-project.firebaseapp.com",
databaseURL: "https://your-project.firebaseio.com",
projectId: "your-project",
storageBucket: "your-project.appspot.com",
messagingSenderId: "123456789",
appId: "1:123456789:web:abc..."
};

IMPORTANT: In Firebase Console, go to Realtime Database → Rules → Change to:

{
"rules": {
".read": true,
".write": true
}
}
